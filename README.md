# Machine Learning Coursework

A collection of machine learning coursework completed as part of my undergraduate studies at Shaheed Sukhdev College of Business Studies, University of Delhi.

The coursework covers fundamental supervised and unsupervised machine learning techniques, including regression, classification, support vector machines, and clustering.

## Topics Covered

- Linear Regression
- Logistic Regression
- Support Vector Machines
- K-Means Clustering
- Data Preprocessing
- Exploratory Data Analysis
- Model Evaluation
- Classification Metrics
- Regression Analysis
- Statistical Analysis
